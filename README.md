# calculator-Greetings
task 1:Perform Basic Mathematical Operations
This Python program is designed to take two numbers as input from a user and perform the four basic mathematical operations on them:
Addition
Subtraction
Multiplication
Division
The program then displays the result of each operation on the screen.
task 2:This simple Python program is designed to take a user's first and last name as input, combine them to form a full name, and display a personalized greeting message. 
Takes user input for first name and last name.
Concatenates names into a full name.
Outputs a personalized greeting.
